# Ledge probe work order

The native desktop autoplay profile reports the shared ledge probe among the
leading navigation costs. Most tested geometry is outside the body's reach.
Check the height band and side reach before the tilt test and world-space body
envelope. Keep the same tilt, clearance, world bounds, and nearest-contact rules.

Stream line ledges in source order. The probe reads them once and does not need
a temporary list. Blocks must still precede lines so equal-distance contacts
keep their existing priority.

Measure both accepted and refused contacts, both wall sides, and rotated gravity.
Compare contact bits as well as timing. A faster probe does not establish the
effect on a full navigation graph or a desktop frame.
