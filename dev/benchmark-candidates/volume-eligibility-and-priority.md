# Apply volume eligibility before priority

A move can publish several volumes on one frame. Only an eligible volume can
win the contact. A higher-priority volume that refuses the victim's posture
must not suppress a lower-priority volume that accepts it. Apply the same rule
when a volume can reach a guard.

A regression fixture must use the move's real rank and shared contact ledger.
Several unranked boxes can prove the target filter and still miss a fault in
priority arbitration. A headless fight with the authored move checks this join.

The contact ledger still belongs to the pulse. Once an eligible volume lands,
its siblings must not hit the same victim again when that victim changes posture.
