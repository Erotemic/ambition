# Archived reviews and correspondence

This directory contains dated reviews, model-to-model correspondence, completed
audit reports, and other historical evidence retained for investigation. It is
**not** a live planning or execution authority.

Current work is routed through [`../../planning/README.md`](../../planning/README.md),
the self-replenishing 72-hour queue, focused planning documents, and durable
architecture/system documentation. Historical review text may explain why a
decision was made, but current source and current durable documentation win when
they disagree.
