* (FOUND 2026-07-28, test-infrastructure hazard worth knowing) **An app-level test that changes a setting edits the developer's real config.** `UserSettings` loads from `~/.local/share/ambition/settings.ron` at startup and `save_settings_on_change` writes it back, so the first version of the title-menu test muted this machine and then failed on every later run — passing alone, failing in the suite, which is the signature of a side effect outside the process.
