# Ports a script may name

Generated by `cargo run -p ambition_platformer2d_runtime --features script_modules --example script_port_reference > docs/sdk/script-ports.md` from each port's own description (`ambition_extension_sdk::structure`); edit the port, not this page.

A script reads its trigger as `this.trigger` and submits a request with
`this.requests.push(request("<alias>", #{ .. }))`: `request` checks the value against the port's description where it is called, so a misspelt field, a wrong kind or a missing required field names the script's line. A field marked with a value under "when absent" may be left out. Numbers are `f32`; a script may not write NaN or an infinity. How a script is loaded: [iterating without a rebuild](../recipes/iterating-without-a-rebuild.md).

## `module_entity_tick`

Port `ambition.world.module_entity_tick@2`, trigger: read as `this.trigger`.

| field | value | meaning |
|---|---|---|
| `position` | [x, y] | The entity's centre (world units, +Y down). |
| `remaining_s` | number | Seconds of lifetime left, after this tick's aging; above zero. |
| `nearest_enemy` | [x, y] or () | The centre of the nearest hittable `Enemy`-side body in the entity's own live room, or `()` when there is none. |
| `params` | table of text to one of: a number \| text \| a bool | The spawn's params, by name. |
| `touchers` | list of { position: [x, y], size: [x, y], velocity: [x, y] } | The hittable bodies whose box meets the entity's, any side, in identity order. |

## `projectile`

Port `ambition.projectiles.spawn@1`, request: `this.requests.push(request("<alias>", #{ .. }))`.

| field | value | when absent | meaning |
|---|---|---|---|
| `origin` | [x, y] | required | Where the shot starts (world units, +Y down). |
| `dir` | [x, y] | required | Its direction; the domain normalizes it. |
| `speed` | number | required | World units per second. |
| `damage` | integer (i32) | required | Damage to the body it hits. |
| `max_lifetime` | number | required | Seconds before it expires. |
| `half_extent` | [x, y] | required | Half its width and height. |
| `gravity` | number | `0.0` | Downward acceleration per second; zero for a straight shot. |
| `visual_id` | text | `""` | A named projectile look, for the render layer only; empty for the generic one. |
| `bounces` | integer 0..=255 | `0` | How many support-face landings it bounces off before it expires. |
| `bounce_on_world_contact` | bool | `false` | Whether world contact bounces it rather than expiring it. |
| `boomerang_return_s` | number or () | `()` | Seconds until it turns and comes back, or `()` for never. |
| `splash_half_extent` | number | `0.0` | Half the size of the burst it deals where it lands; zero for none. |

## `sound`

Port `ambition.feedback.body_sound@2`, request: `this.requests.push(request("<alias>", #{ .. }))`.

| field | value | when absent | meaning |
|---|---|---|---|
| `cue` | text | required | The sound cue's id in the game's sound registry (`world.rock.hit`). |
| `at` | one of: [x, y]: a point in the world \| (): the body the invocation ran for | `()` | Where it plays. |

## `pull_bodies`

Port `ambition.world.pull_bodies@1`, request: `this.requests.push(request("<alias>", #{ .. }))`.

| field | value | when absent | meaning |
|---|---|---|---|
| `center` | [x, y] | required | The point bodies are pulled toward (world units, +Y down). |
| `radius` | number | required | How far from `center` a body's centre may be and be pulled. |
| `rate` | number | required | The part of its distance a body closes per second (a move of `min(rate * dt, 1)` of it this tick). |

| field | value | when absent | meaning |
|---|---|---|---|
| `toucher` | integer (u32) | required | Which of this tick's `touchers` (its index in the trigger's list). |
