# Vision docs index

**Direction lives in [`../planning/`](../planning/README.md).**
`planning/vision.md` is the product vision and `planning/decision-principles.md`
holds the maintainer's decision criteria. This directory keeps auxiliary
reference notes, not plan:

- [`endgame-sandbox.md`](endgame-sandbox.md) — movement-instrument room design
  notes.
- [`reference-material.md`](reference-material.md) — external reference links
  and inspiration.

Mechanics status is tracked in
[`../mechanics/expressibility-checklist.md`](../mechanics/expressibility-checklist.md).
